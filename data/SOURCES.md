# Bundled reference data

Generated on 2026-10-27. App runtime reads local files; it does not send collection data or location searches to external services.

- **Cities, coordinates, country codes, and city aliases:** GeoNames, packaged by geonamescache 3.0.2 (default cities15000). 34,006 entries in this snapshot. GeoNames data is [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Source and attribution: https://www.geonames.org/ and https://download.geonames.org/export/dump/readme.txt. City records were reduced to ID, name, country, Chinese-character aliases, province/state, population, and coordinates rounded to five decimals. Administrative region labels come from https://download.geonames.org/export/dump/admin1CodesASCII.txt. The list covers larger settlements and some administrative seats; it is not a complete list of towns or addresses. geonamescache's MIT notice is in GEONAMESCACHE-LICENSE.txt.
- **Country/area labels, current tender currency codes and currency decimal precision:** Babel 2.18.0, derived from Unicode CLDR. Country labels are Chinese and English. Cities display a Chinese name when available, alongside upstream primary and province/state names. Chinese display names were extracted from https://download.geonames.org/export/dump/alternateNamesV2.zip, selecting Chinese-language entries and excluding records marked historical, colloquial, or with an end date; preferred-name flags and simplified-Chinese language tags guide ranking. The abbreviated Chinese-character alias list remains searchable. Retired country/area codes absent from the CLDR territory labels were omitted. Currency snapshot is for the generation date; this is a list for recording purchases, not a currency conversion or exchange-rate service. Babel BSD notice: BABEL-LICENSE.txt. CLDR terms: https://www.unicode.org/license.txt.
- **World land outline:** Natural Earth `ne_110m_land`, https://naturalearth.s3.amazonaws.com/110m_physical/ne_110m_land.zip. Public domain: https://www.naturalearthdata.com/about/terms-of-use/. Converted to a 1000 × 500 SVG in an equirectangular projection. Land only, with no political boundaries. It is an overview map, not a navigation map.

Regenerate with `tools/build_reference_data.py`; its docstring lists build dependencies and source downloads. They are only needed to rebuild data, not to run Cabinet.
