# 使用藏阁

[English](guide.md) · [返回项目首页](../README.zh-CN.md)

## 添加藏品

打开「新增藏品」，填写名称与类别，点击「收入藏阁」保存，其余信息均可选填。

每件藏品可上传一张 JPEG、PNG、WebP 或 GIF 照片，也可使用图片网址。图片与表单总大小需小于 10 MB；同时填写网址并上传照片时，优先使用上传照片。目前暂不支持 HEIC 和多张照片。

日期记得多少就填多少：只有年、年与月，或完整年月日。完全不清楚时，三项都留空。

国家 / 地区与城市可在下拉框中搜索。找不到某个城镇时，可以留空城市，把具体位置写在来源里。价格也可留空；填写金额后再选择币种，或使用当地货币快捷按钮。

当前版本支持新增与浏览藏品，暂未提供界面内的编辑、删除功能。

## 回看旅迹

打开「旅迹」，在时间轴和世界地图之间切换，两种视图都可按入藏年份筛选。

在地图上点击标记或地点按钮，即可查看对应藏品；使用缩放按钮和拖动探索地图。未选择城市的藏品仍保留在时间轴和地图的待定位列表中。

## 备份收藏

停止应用，再一起复制项目目录中的：

- `museum.db`：藏品记录。
- `storage/`：上传的照片。

恢复时将两者放回对应位置，再启动应用。它们不会提交到 Git，所以推送项目到 GitHub 不会备份个人收藏。

## 本地使用

保留默认的本机访问地址。当前没有登录系统，适合在自己的电脑上使用。

地图和城市搜索可在本地运行；使用网址添加的图片以及 Google Fonts 字体需要联网加载。
